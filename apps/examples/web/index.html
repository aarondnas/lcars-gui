LCARS for the web

@lcars-gui/federation brings the Library Computer Access/Retrieval System of The Next Generation, Deep Space Nine and Picard to your apps – as React components and as plain HTML/CSS with a tiny script for interaction. Everything on this page is built with the library.

  • React components and plain HTML/CSS
  • Three themes: TNG, DS9, Picard
  • Red and yellow alert for whole screens
  • Synthesized interface sounds – no audio files
  • Responsive: sidebars become button rows
  • Fully typed, tree-shakeable, SSR-ready
npm install @lcars-gui/federation

Get started

React

import "@lcars-gui/federation/ui.css";
import { Frame, Button, LcarsRoot, SoundProvider } from "@lcars-gui/federation/react";

export default function App() {
  return (
    <SoundProvider>
      <LcarsRoot theme="tng">
        <Frame
          title="Bridge"
          topLabel="47-1138"
          sidebar={<Button shape="rect" align="bottom-right">Tactical</Button>}
        >
          Warp core stable.
        </Frame>
      </LcarsRoot>
    </SoundProvider>
  );
}

Interfaces of the Star Empire

@lcars-gui/romulus is a complete UI kit in the style of the Romulan Star Empire: glowing lines on dark surfaces, chamfered corners, talon-shaped accents and diamonds instead of circles. Same API ideas as the Federation package – a completely different look.

  • React components and plain HTML/CSS
  • Three themes: Warbird, Tal Shiar, Free State
  • Red and yellow alert
  • Lower, triangle-wave interface sounds
  • Prefixed CSS variables – mix with other factions
  • Fully typed, tree-shakeable, SSR-ready
npm install @lcars-gui/romulus

Get started

React

import "@lcars-gui/romulus/ui.css";
import { Panel, Button, RomulusRoot, SoundProvider } from "@lcars-gui/romulus/react";

export default function App() {
  return (
    <SoundProvider>
      <RomulusRoot theme="warbird">
        <Panel code="R-7734" title="Tactical" sidebar={<Button>Cloak</Button>}>
          Cloaking device engaged.
        </Panel>
      </RomulusRoot>
    </SoundProvider>
  );
}
